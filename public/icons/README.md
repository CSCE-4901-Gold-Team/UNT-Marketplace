# App Icons

Place your app icons in this directory with the following sizes:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Quick Generation

You can use online tools to generate these from a single image:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

Or use an image editor to resize your logo to each size.

## Recommended:
Start with a 512x512 PNG image with your UNT Marketplace logo.
